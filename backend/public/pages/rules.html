How rules run
  1. Rules run top to bottom: position 1 first. Drag a rule (or use ▲ ▼) to change the order. New rules go to the bottom.
  2. Every matching rule runs, not just the first. Each rule sees the transaction as the earlier rules left it.
  3. If two rules set the same thing (category, payee, cleared), the lower one wins. Notes from all matching rules are added together, and the same note is never added twice.
  4. A rule with “stop after this rule” ends the run when it matches.
  5. Disabled rules are skipped.
  6. Rules run when a transaction is added or imported. Editing a transaction never runs them. Your existing transactions change only if you press Re-apply rules and confirm.
